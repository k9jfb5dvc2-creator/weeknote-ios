## 安装后由用户核对

- 日期、周几、跨月跨年和“今天”正确；七天日期条、搜索筛选、完成恢复及删除撤销正常。
- 中文九宫格、拼音和软键盘回车能连续编号；中间换行、整行删除、跨行替换和多行粘贴不丢正文。`2026.11.2 会议`、`3.14记录`、`12:30开会` 保留数字。
- “下一项 / 同项换行 / 完成”可用；空编号不存为正文；关闭重开后内容完整。键盘、刘海与底部手势区不遮挡光标和保存按钮。
- 在设置页主动开启通知。拒绝时任务仍保存，界面显示权限状态；允许后设置约两分钟后的任务，分别检查前台、锁屏和切至其他 App 时的提醒。
- 通知中的“完成”“10 分钟后”能持久化；重新打开及重启后状态一致。旧通知不能覆盖新任务内容，网页未加载时的通知操作也能保存。
- 超过 60 个未来提醒时只排最近一批并显示超出数量；打开 App、完成或取消任务后核对补入。长期不打开 App 时，不把超出排程范围的全部提醒都必达作为通过条件。
- 导出到“文件”，重复导入同一 JSON 不重复任务；本机同 ID 的更新保留。导入后继续编辑再撤销，应保留后续修改。错误文件、数据损坏和取消文件选择不能清空已有内容。
- 免费签名到期前用 AltStore 刷新；续签不删除 App。源码包不含个人便签，导出的备份由用户自行保管。

原生桥只允许 App 本地页面主框架调用；外部导航和未知方法不可访问数据。通知动作先保存再通知页面，恢复前台先同步原生变更，防止旧网页状态覆盖后台操作。[Apple 通知代理](https://developer.apple.com/documentation/usernotifications/unusernotificationcenterdelegate)、[WKFrameInfo](https://developer.apple.com/documentation/webkit/wkframeinfo)
